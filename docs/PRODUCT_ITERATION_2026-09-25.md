# inVoice 0.2 — Mac 产品体验迭代

本次面向本机日常使用，在已有工作区基础上完成；没有覆盖先前的设备、固件与语音链路改动。

## 使用体验

- 原设置窗口升级为可缩放、记忆尺寸的中文侧栏工作台。主动启动应用时直接打开；登录启动时保持后台。
- 冷启动期间显示准备状态，短时自动检查就绪，避免把模型启动过程误报为需要重新设置。
- 概览提供实际运行状态、输出方式切换、语音练习区、历史与助手入口。
- 默认按用户选择采用 **中文转自然英文并润色**；支持原样转写与同语言整理。
- 历史页支持搜索、语音/全部筛选、固定和复制；继续使用现有本地数据库。
- 权限与诊断页检查经过认证的真实服务身份、协议和运行状态，可恢复未启动的语音服务。
- 提示词默认折叠，避免初次打开就面对大量配置；重置提示词有明确确认。
- 本地助手新增空白页引导、输入提示、新对话、失败重试和复制反馈，移除未接通的模式、附件、麦克风和评价按钮。
- 听写错误使用独立提示，可直接打开诊断；不再把错误当作可复制的听写结果。
- 通用页提供登录启动与剪贴板收集开关，暂停后停止剪贴板轮询。没有自动开启登录项。

## 性能与可靠性

- Ollama 请求显式关闭 thinking，避免简单文字变换产生大量隐藏推理。
- 空 prompt 预热仅加载模型，使用 actor 按模型合并预热，冷却后可以重新预热。
- 助手流式请求使用单独的等待时间，检查完成标记；未完成的流不再显示为成功。
- 剪贴板搜索防抖 120 ms，结果携带递增代次，过期查询不能覆盖当前查询。
- 图片预览使用最大 1000 px 的缩略图与 48 MB/30 项缓存，图片尺寸读取元数据。
- 剪贴板不再自动下载复制的远程图片网址；忽略密码、隐藏和临时剪贴板标记。
- 统计在 actor 上读取日志末尾最多 512 KB；只统计成功会话，以结束时间减松开时间计算等待。
- doctor 脚本在进程内部读取本地 token，认证检查服务，不在命令行或日志中打印 token。

## 本机验证

- Release（Apple Silicon）构建通过，安装包签名检查通过。
- Swift 核心测试 51 项通过；Python 侧车测试 8 项通过。
- `scripts/doctor.sh` 全部通过，0 警告。
- 原生界面已验证：主窗口重新打开、默认英文润色、输出方式页、模型页、诊断检查、助手输入并实际返回“已就绪”。
- 真实 `ASRClient` / `OfflineLLMClient` / `LLMRouter` 实测通过：中文识别、英文润色、助手流式输出、模型不可用时保留原文、直接输出跳过模型。
- 输入音频由 macOS `say` 合成，没有读取用户录音。测试文本为“请在周五之前完成产品体验的优化，并且保留中文输出”。
- 一次对照测试：同一段中文轻度整理，模型已加载时默认 thinking 请求 43,556 ms，关闭后 603 / 433 ms；输出一致。这是单一样本，不能代表所有场景。
- 真实客户端英文润色请求 1,325 ms；识别请求服务端 1,139 ms（同时有构建负载）。首次冷加载约 13.4 秒。
- 仍需真实使用验证的范围：长时间连续口述、不同口音/噪声、各第三方输入框与可选硬件。没有宣称全面声学准确率或端到端延迟指标。

## 本机安装

应用：`~/Applications/inVoice.app`

本次迭代前的应用备份：`~/Library/Application Support/VoiceOps/backups/inVoice-before-product-20260925.app`

按住 `Fn` 听写；`⌘⌥P` 打开工作台；`⌘⌥T` 打开助手。

实现参考：[Ollama Chat API](https://docs.ollama.com/api/chat)、[Ollama Generate API](https://docs.ollama.com/api/generate)。
